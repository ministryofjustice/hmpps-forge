# Building journeys
Journeys are the foundation of everything you build with Forge. A
journey defines the pages, fields, routing, and behaviour that make up
a multi-page form. This section covers how to author them, from the
basic structure through to validation.

If you are new to Forge, this is the best place to start. The guides
are written in reading order, with each one building on the concepts
introduced before it.

{{slot:toc}}

---

## Where to start

Begin with [Defining a journey](defining-a-journey) to understand the
top-level structure, then work through
[Defining steps](defining-steps) and
[Defining blocks and fields](defining-blocks-and-fields) to learn how
pages and form inputs are authored. The remaining guides cover routing,
navigation, hooks, and validation.

These guides focus on the declarative authoring side of Forge: how to
define what your journey looks like and how users move through it.
Custom server-side logic, such as calling APIs, transforming data, or
managing session state, is covered separately in the Building
functions & components section.
